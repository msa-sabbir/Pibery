# Pibery Website Builder 🚀

Pibery হলো একটি মডার্ন এবং পাওয়ারফুল ই-কমার্স ওয়েবসাইট বিল্ডার প্ল্যাটফর্ম। এটি ব্যবসায়ীদের জন্য কোনো প্রকার কোডিং ছাড়াই প্রফেশনাল ই-কমার্স ওয়েবসাইট তৈরির অভিজ্ঞতা নিশ্চিত করে। এতে রয়েছে অত্যন্ত শক্তিশালী অ্যাডমিন কন্ট্রোল প্যানেল এবং গ্রাহকবান্ধব ফ্রন্টএন্ড ফিচার।

## 🛠️ টেকনোলজি স্ট্যাক ও আর্কিটেকচার

আপনার প্রজেক্টটি একটি সুশৃঙ্খল **MVC (Model-View-Controller)** প্যাটার্নে তৈরি এবং এর টেকনোলজি স্ট্যাক নিচে দেওয়া হলো:

| কম্পোনেন্ট | টেকনোলজি |
|------------|-----------|
| **Frontend** | HTML5, CSS3, Google Fonts (*Inter*), FontAwesome Icons, Vanilla JavaScript (ES6+) |
| **টেমপ্লেট ইঞ্জিন** | Embedded JavaScript (EJS) |
| **Backend** | Node.js, Express.js (RESTful API) |
| **Database** | MongoDB, Mongoose ODM |
| **Authentication** | JWT, Session-based Auth |
| **পেমেন্ট গেটওয়ে** | PayPal, Stripe (upcoming) |

## 📂 প্রজেক্ট স্ট্রাকচার (Project Structure)

```text
pibery-website-builder/
├── config/               # ডাটাবেজ কানেকশন কনফিগারেশন
│   └── db.js

│   ├── authController.js
│   ├── shopController.js
│   ├── productController.js
│   ├── businessController.js
│   └── storeController.js # অ্যাডমিন ও ইউজার সাইট ফিচার লজিক
├── models/               # ডাটাবেজ মডেল (Mongoose Schemas)
│   ├── User.js           # ইউজার ও রোল মডেল
│   ├── Shop.js           # শপ ও সাবডোমেন মডেল
│   ├── Product.js        # প্রোডাক্ট ও ইনভেন্টরি মডেল
│   ├── Order.js          # অর্ডার ট্র্যাকিং ও ফুলফিলমেন্ট মডেল
│   ├── Customer.js       # কাস্টমার প্রোফাইল ও লয়্যালটি ডাটা
│   ├── Staff.js          # স্টাফ রোল ও পারমিশন কন্ট্রোল
│   └── Marketing.js      # ডিসকাউন্ট কুপন ও ক্যাম্পেইন ম্যানেজমেন্ট
├── routes/               # API রাউটিং
│   ├── authRoutes.js
│   ├── shopRoutes.js
│   ├── productRoutes.js
│   ├── businessRoutes.js
│   └── storeRoutes.js    # স্টোর ফিচার রাউটস
├── views/                # ফ্রন্টএন্ড ভিউ (EJS & HTML)
│   ├── partials/         # হেডার ও ফুটার পার্টস
│   ├── dashboard.ejs     # মেইন বিল্ডার ড্যাশবোর্ড ও ইন্টারফেস
│   ├── index.html
│   └── shop-template.ejs
├── public/               # স্ট্যাটিক অ্যাসেটস (CSS, JS, Images)
├── .env                  # এনভায়রনমেন্ট ভেরিয়েবল
├── app.js                # মেইন সার্ভার ফাইল (Entry Point)
├── package.json          # ডিপেন্ডেন্সি ও প্যাকেজ ফাইল
└── README.md             # প্রজেক্ট ডকুমেন্টেশন








✨ ফিচারসমূহ (Features List)

🎛 ১. প্ল্যাটফর্মের মেইন ওনার (আপনার) কন্ট্রোল প্যানেল

বর্তমানে আপনার এই প্ল্যাটফর্মের কন্ট্রোল সেন্টারে যে ফিচারগুলো যুক্ত করা হয়েছে:

ফিচার বিবরণ
স্টুডিও ও ক্যানভাস বিল্ডার প্ল্যাটফর্মের ভেতর থেকেই ড্র্যাগ-অ্যান্ড-ড্রপ বা ক্লিকের মাধ্যমে লাইভ পেজ স্ট্রাকচার বা কম্পোনেন্ট (যেমন: হিরো সেকশন, ফিচার গ্রিড, প্রাইসিং টেবিল ইত্যাদি) যুক্ত বা ডিলিট করার ব্যবস্থা।
সেন্ট্রাল অ্যাডমিন কন্ট্রোল প্যানেল রিয়েল-টাইম ড্যাশবোর্ড ওভারভিউ, লাইভ সেলস ও ট্রাফিক অ্যানালিটিক্স ট্র্যাক করার সুবিধা।
ইনভেন্টরি ও অর্ডার ম্যানেজমেন্ট কাস্টমারদের অর্ডার প্রসেস করা, স্টক ট্র্যাক করা এবং শিপিং ম্যানেজ করার ব্যাকএন্ড লজিক।
মার্চেন্ট প্রোডাক্ট ম্যানেজমেন্ট নতুন প্রোডাক্ট অ্যাড করার ফর্ম এবং ডাইনামিকালি তা স্টোরে পাবলিশ করার সিস্টেম।
থিম কাস্টমাইজেশন ডার্ক এবং লাইট থিম টগল করার সুবিধা।
প্রজেক্ট এক্সপোর্ট তৈরি করা স্টোর কম্পাইল বা এক্সপোর্ট করার সিমুলেটর।

---

🛠️ ২.ক. মার্চেন্ট বা শপ ওনারের নিজস্ব এডমিন সাইট (Admin Features for Store Creators)

আপনার প্ল্যাটফর্ম ব্যবহার করে যারা নতুন ই-কমার্স ওয়েবসাইট বানাবে, তারা তাদের সাইটের জন্য যে এডমিন ফিচারগুলো পাবে:

ফিচার বিবরণ
ড্যাশবোর্ড ও সেলস অ্যানালিটিক্স মোট আয় (Total Revenue), মোট অর্ডার এবং মোট কাস্টমারের হিসাব রিয়েল-টাইমে দেখার সুবিধা।
প্রোডাক্ট ও ক্যাটালগ ম্যানেজমেন্ট নিজেদের দোকানে নতুন প্রোডাক্ট, দাম, ছবি ও বিবরণ যুক্ত করা এবং স্টক আপডেট করা।
অর্ডার প্রসেসিং সেন্টার কাস্টমারদের নতুন অর্ডারগুলো দেখা এবং সেগুলোর স্ট্যাটাস (যেমন: Pending, Processing, Completed) পরিবর্তন বা ম্যানেজ করা।
কাস্টমার রিলেশনশিপ (CRM) ক্রেতাদের তথ্য ও প্রোফাইল ম্যানেজমেন্ট।
মার্কেটিং ও কুপন টুলস ডিসকাউন্ট কুপন কোড তৈরি এবং প্রচারণামূলক ক্যাম্পেইন চালানোর সুবিধা।

---

🛍️ ২.খ. সাধারণ ক্রেতা বা ইউজারদের শপফ্রন্ট সাইট (Storefront Features for Customers)

ফিচার বিবরণ
স্মার্ট প্রোডাক্ট ডিসকভারি কিওয়ার্ড সার্চ, ক্যাটাগরি এবং প্রাইস ফিল্টার করার সুবিধা।
শপিং কার্ট ও গেস্ট চেকআউট সহজে কার্টে প্রোডাক্ট যোগ করা, পরিমাণ কমানো-বাড়ানো এবং নিরাপদ গেস্ট চেকআউট করার সিস্টেম।
লাইভ অর্ডার ট্রাকিং অর্ডার করার পর পণ্য কোথায় আছে তা রিয়েল-টাইমে ট্র্যাক করার সুবিধা।
কাস্টমার লয়্যালটি ও রিওয়ার্ড নিয়মিত কেনাকাটায় পয়েন্ট অর্জন এবং ডিসকাউন্ট পাওয়ার সুবিধা।

🚀 ইন্সটলেশন ও রান (Setup Guide)

পূর্বশর্ত (Prerequisites)

· Node.js (v14 বা তার বেশি)
· MongoDB (লোকাল বা ক্লাউড)
· npm বা yarn

ধাপসমূহ

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/pibery-online/Pibery-Website-Builder.git
cd Pibery-Website-Builder

# ২. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ৩. .env ফাইল তৈরি করুন (নিচের উদাহরণ অনুসারে)
# PORT=3000
# MONGODB_URI=mongodb://localhost:27017/pibery
# JWT_SECRET=your_secret_key_here

# ৪. ডেভেলপমেন্ট সার্ভার রান করুন
npm run dev

# অথবা প্রোডাকশন মোডে
node app.js

# ৫. ব্রাউজারে প্রবেশ করুন
# http://localhost:3000
```
