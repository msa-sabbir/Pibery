# Pibery Website Builder 🚀

Pibery হলো একটি মডার্ন এবং পাওয়ারফুল ই-কমার্স ওয়েবসাইট বিল্ডার প্ল্যাটফর্ম। এটি ব্যবসায়ীদের জন্য কোডিং ছাড়াই প্রফেশনাল ই-কমার্স ওয়েবসাইট তৈরির অভিজ্ঞতা নিশ্চিত করে। এতে রয়েছে শক্তিশালী অ্যাডমিন কন্ট্রোল প্যানেল এবং গ্রাহকবান্ধব ফ্রন্টএন্ড ফিচার।

---

## 📂 প্রজেক্ট স্ট্রাকচার (Project Structure)

আপনার প্রজেক্টটি একটি সুশৃঙ্খল MVC (Model-View-Controller) আর্কিটেকচারে সাজানো হয়েছে:

```text
pibery-website-builder/
├── controllers/          # বিজনেস লজিক হ্যান্ডলার
│   └── storeController.js # স্টোর ফিচারসমূহ (অ্যাডমিন ও ইউজার)
├── models/               # ডাটাবেজ মডেল
│   ├── Customer.js       # কাস্টমার ও লয়্যালটি ডাটা
│   ├── Staff.js          # স্টাফ রোল ও পারমিশন
│   └── Marketing.js      # ডিসকাউন্ট ও কুপন ম্যানেজমেন্ট
├── routes/               # API রাউটিং
│   └── storeRoutes.js    # স্টোর ফিচার রাউটস
├── views/                # ফ্রন্টএন্ড ভিউ (EJS)
│   └── dashboard.ejs     # মেইন বিল্ডার ড্যাশবোর্ড
├── public/               # স্ট্যাটিক অ্যাসেটস (CSS, JS, Images)
├── app.js                # মেইন সার্ভার ফাইল (Entry Point)
├── package.json          # ডিপেন্ডেন্সি ও প্যাকেজ ফাইল
└── README.md             # প্রজেক্ট ডকুমেন্টেশন
