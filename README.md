# Pibery Website Builder 🚀

Pibery হলো একটি মডার্ন এবং পাওয়ারফুল ই-কমার্স ওয়েবসাইট বিল্ডার প্ল্যাটফর্ম। এটি ব্যবসায়ীদের জন্য কোনো প্রকার কোডিং ছাড়াই প্রফেশনাল ই-কমার্স ওয়েবসাইট তৈরির অভিজ্ঞতা নিশ্চিত করে। এতে রয়েছে অত্যন্ত শক্তিশালী অ্যাডমিন কন্ট্রোল প্যানেল এবং গ্রাহকবান্ধব ফ্রন্টএন্ড ফিচার।

---

## 📂 প্রজেক্ট স্ট্রাকচার (Project Structure)

আপনার প্রজেক্টটি একটি সুশৃঙ্খল MVC (Model-View-Controller) আর্কিটেকচারে সাজানো হয়েছে:

```text
pibery-website-builder/
├── controllers/          # বিজনেস লজিক হ্যান্ডলার
│   └── storeController.js # অ্যাডমিন ও ইউজার সাইট ফিচার লজিক
├── models/               # ডাটাবেজ মডেল
│   ├── Customer.js       # কাস্টমার প্রোফাইল ও লয়্যালটি ডাটা
│   ├── Staff.js          # স্টাফ রোল ও পারমিশন কন্ট্রোল
│   └── Marketing.js      # ডিসকাউন্ট কুপন ও ক্যাম্পেইন ম্যানেজমেন্ট
├── routes/               # API রাউটিং
│   └── storeRoutes.js    # নতুন যুক্ত স্টোর ফিচার রাউটস
├── views/                # ফ্রন্টএন্ড ভিউ (EJS)
│   └── dashboard.ejs     # মেইন বিল্ডার ড্যাশবোর্ড ও ইন্টারফেস
├── public/               # স্ট্যাটিক অ্যাসেটস (CSS, JS, Images)
├── app.js                # মেইন সার্ভার ফাইল (Entry Point)
├── package.json          # ডিপেন্ডেন্সি ও প্যাকেজ ফাইল
└── README.md             # প্রজেক্ট ডকুমেন্টেশন






✨ ফিচারসমূহ (Features List)
​🛠️ অ্যাডমিন প্যানেল (মালিক ও কর্মীদের জন্য)
​ড্যাশবোর্ড: বিক্রয়, অর্ডার এবং ভিজিটর সংখ্যার রিয়েল-টাইম ওভারভিউ।
​অর্ডার ম্যানেজমেন্ট: প্রক্রিয়াকরণ, প্যাকিং স্লিপ, শিপিং লেবেল প্রিন্ট এবং রিটার্ন/রিফান্ড হ্যান্ডেলিং।
​পণ্য ও ইনভেন্টরি: নতুন পণ্য যোগ/এডিট, স্টক ট্র্যাকিং এবং বাল্ক আপডেট।
​গ্রাহক ব্যবস্থাপনা (CRM): কাস্টমার প্রোফাইল, কেনার ইতিহাস এবং টার্গেটেড মার্কেটিং।
​অ্যানালিটিক্স ও রিপোর্ট: বিক্রয় ও গ্রাহক আচরণের বিস্তারিত রিপোর্ট।
​মার্কেটিং: ডিসকাউন্ট কুপন তৈরি, ইমেইল ক্যাম্পেইন এবং সোশ্যাল মিডিয়া কানেক্টিভিটি।
​পারমিশন কন্ট্রোল: কর্মীদের জন্য নির্দিষ্ট কাজের এক্সেস নিয়ন্ত্রণ।
​অ্যাপ ইন্টিগ্রেশন: অ্যাপ স্টোর থেকে অতিরিক্ত ফাংশনালিটি যোগ করার সুবিধা।
​🛍️ ইউজার সাইট (গ্রাহকদের জন্য)
​পণ্য ব্রাউজিং: উন্নত সার্চ, ফিল্টার (দাম, সাইজ, রঙ) ও সর্টিং।
​প্রোডাক্ট পেজ: হাই-কোয়ালিটি মিডিয়া গ্যালারি, রিভিউ ও রেটিং।
​কার্ট ও চেকআউট: গেস্ট চেকআউট এবং একাধিক পেমেন্ট মেথড (PayPal/Card)।
​কাস্টমার অ্যাকাউন্ট: অর্ডার হিস্ট্রি, উইশলিস্ট এবং পাসওয়ার্ডহীন লগইন সুবিধা।
​অর্ডার ট্র্যাকিং: ডেলিভারি স্ট্যাটাস দেখার জন্য রিয়েল-টাইম ট্র্যাকিং।
​স্বয়ংক্রিয় রিটার্ন: গ্রাহকদের নিজস্ব ড্যাশবোর্ড থেকে রিফান্ড রিকুয়েস্ট।
​লয়্যালটি প্রোগ্রাম: কেনাকাটায় পয়েন্ট বা রিওয়ার্ড অর্জনের সুবিধা।
